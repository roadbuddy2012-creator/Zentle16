# 곁 쇼핑 비서 — 사용 가능한 시안

`gyeot-app.html` 한 파일로 된 웹 앱입니다. claude.ai 아티팩트로 게시해서 쓰며, 아티팩트가 주는 기능(`sample` AI 호출, `db` 사용자별 비공개 저장, `user`, `assets` 사진 보관)을 사용합니다. 그 밖에서는 AI 없이 이 기기 브라우저에만 저장되는 모드로 동작합니다.

## 지금 되는 것

| 요구 | 구현 |
| --- | --- |
| 목적을 알아듣고 2~3개만 자세히 | 조건 확인 단계에서 목적(intent)을 한 줄로 보여 주고, 추천은 2~3개로 줄여 이유·좋은 점·아쉬운 점·사이즈·확인할 것을 함께 보여 줌 |
| 더 싼 곳(테무·알리·쿠팡) | 손해가 적을 때만 대안을 제안하고 가격 차이·배송 기간·품질·반품·주의점을 설명 |
| 사기 좋은 때 | 코드에 넣은 세일 일정(`SALES`, 2026-10-08 기준 확정/예상 구분)만 근거로 "지금 사기 / 기다리기"를 설명. 홈에 다가오는 세일 표시 |
| 가진 옷 확인 | 옷장 목록을 보고 가진 것으로 해결되면 "안 사도 돼요"를 먼저 제안. 패션 부탁이면 "혹시 ○○ 있으세요?"라고 묻고 그 자리에서 사진·말로 추가 |
| 가진 신발·액세서리로 코디 | 추천마다 옷장 아이템을 골라 함께 보여 줌 |
| 체형을 미리 알고 입혀보기 | 키·사이즈·선호 핏·전신 사진으로 체형을 정리해 두고, 패션 추천의 상세 화면에서 사이즈·맞음새·코디를 보고함(이미지 합성은 아님) |
| 옷 사진 올리기를 덜 귀찮게 | 사진 한 장(거울 셀카·펼친 옷·옷걸이)에서 여러 벌을 자동으로 나누고, 말 한 줄로도 등록, 산 옷은 자동으로 옷장에 넣음. 필요할 때만 묻는 방식 |
| 평점·리뷰·판매량 상위 | AI에게 세 조건을 함께 만족하는 스테디셀러를 우선하라고 지시하고, 쿠팡 판매량순·네이버 리뷰 많은순·알리 주문 많은순 링크로 바로 확인하게 함 |

결제 금액(할인·한도·Pay 적립·포인트·무이자 할부)은 AI가 아니라 코드가 계산합니다.

## 서버가 있어야 되는 것

- **사이트별 실제 평점·리뷰 수·판매량을 합친 순위**: 이 페이지는 외부 사이트를 읽을 수 없고, AI도 실시간 검색을 하지 않습니다. 네이버 쇼핑 검색 API는 리뷰순 정렬을 지원하지 않으므로, 제휴 API(쿠팡 파트너스, 알리 제휴 API 등)나 데이터 제휴로 수집하는 서버가 필요합니다.
- **입은 모습 이미지**: 가상 착용 이미지는 이미지 생성 모델을 연결해야 합니다. 지금은 체형·사이즈 기반의 글 보고서입니다.
- **카드 혜택 정확도**: AI가 모르는 카드는 혜택을 비워 둡니다. 카드 혜택 규칙 DB를 따로 만들어야 합니다.
