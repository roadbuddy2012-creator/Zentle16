# 알구싸구 — 사용 가능한 시안

`algussagu.html` 한 파일로 된 웹 앱입니다. claude.ai 아티팩트로 게시해서 쓰며, 아티팩트가 주는 기능(`sample` AI 호출, `db` 사용자별 비공개 저장, `user`, `comments` 의견 남기기)을 사용합니다. 그 밖에서는 AI 없이 이 기기 브라우저에만 저장되는 모드로 동작합니다. 이전 이름은 "곁"(`gyeot-app.html`)이었고, 계정에 남은 곁의 결제수단·취향·옷장 이름은 처음 열 때 한 번 옮겨 옵니다.

## 흐름 (v5: 나를 먼저 알고, 이미지로 보여 주기)

아래 탭은 **홈 · 쇼츠 · (+) 물어보기 · 찜 · 나**입니다.

1. **나 알려주기(처음 한 번)** — 사진첩에서 내 옷차림·캡처한 상품·저장한 사진을 최대 12장 고르고, 청첩장·택배·카드 결제 문자를 붙여넣을 수 있습니다. AI가 "나의 쇼핑 DNA"(취향 요약, 자주 입는 색, 가진 옷, 다가오는 일정, 결제 문자 속 카드, 쇼핑 습관)를 만들어 인스타 스토리처럼 보여 줍니다. 결제 문자에서 찾은 카드는 지갑에 자동으로 넣고 혜택을 채웁니다.
2. **홈 피드** — 스토리 줄(내 DNA, D-day 일정, 셀럽룩, 세일 D-day) 아래로 "나를 위한 추천" 게시물이 이어집니다. 일정(D-12 결혼식), 가진 옷(사진 속 흰 셔츠와 어울리는 것), 세일 시기에 맞춰 고르고, 내 사진 위에 추천 상품 스티커를 붙인 슬라이드도 보여 줍니다. 가격 줄에는 내 카드로 낼 때의 할인율과 금액이 먼저 나옵니다.
3. **쇼츠** — 추천 상품을 한 화면에 하나씩 세로로 넘겨 봅니다. 오른쪽 버튼으로 찜·더 묻기·판매처 보기·사진 보기·최저가 결제를 합니다.
4. **물어보기** — 가운데 + 버튼으로 시트를 열어 말하듯 묻습니다. 결과는 이미지 카드로 먼저 나오고, 쇼츠로 이어 보거나 칩과 질문으로 다시 고릅니다. 셀럽·스타일 코디도 여기서 합니다.
5. **결제** — "최저가 결제"를 누르면 카드·Pay·포인트·멤버십 조합을 계산합니다. 카드가 없으면 그때 한 번만 등록을 권합니다.

상품 그림은 AI가 상품마다 그리는 단순한 일러스트이고, 화면에 "일러스트"라고 표시합니다. 실제 사진은 "사진 보기"(네이버 이미지 검색)와 판매처 링크로 엽니다. 사진은 이 기기(IndexedDB)에만 저장하고 분석할 때만 AI에 보내며, 붙여넣은 문자는 분석 뒤 저장하지 않습니다.

## 결제 조합 계산 (AI가 아니라 코드가 계산)

- 주문마다 카드·Pay를 배정하는 모든 경우를 따져 실제 부담(할인·캐시백·적립 반영)이 가장 적은 조합을 고릅니다. 카드별 월 할인 한도는 주문끼리 나눠 씁니다. 예: 한도 1만 원 카드는 가장 비싼 주문보다 할인율이 높은 작은 주문 둘에 쓰는 게 이득일 수 있습니다.
- 온라인 결제는 보통 주문 1건에 카드 1장이라, 카드 2장을 쓰려면 주문을 나눕니다. 주문을 나누면 배송비가 따로 붙는 것도 계산에 넣습니다.
- 포인트는 카드 혜택을 깎지 않는 주문에만 쓰고, 깎이면 아껴 두는 쪽이 얼마나 이득인지 알려 줍니다.
- 멤버십은 무료배송과 추가 적립을 반영합니다(쿠팡 와우·배민클럽은 무료배송이 기본값).
- 무이자 할부가 되는 카드는 월 부담도 보여 줍니다.

## 서버나 제휴가 있어야 되는 것

- **상품 사진·쇼츠 영상**: claude.ai 아티팩트는 보안 정책상 다른 사이트의 이미지·영상·데이터를 불러올 수 없습니다. 그래서 지금은 AI가 그린 일러스트와 사용자의 사진을 쓰고, 상품 사진은 링크로 엽니다. 실제 앱에서는 네이버 쇼핑 검색 API처럼 상품 사진·상품 페이지 링크·최저가를 주는 API를 서버에 붙이면 바로 보여 줄 수 있습니다.
- **실시간 평점·리뷰 수·판매량 순위**: 이 페이지는 외부 사이트를 읽을 수 없고, AI도 실시간 검색을 하지 않습니다. 결과는 AI가 아는 정보 기준이며 가격은 예상가입니다. 제휴 API(쿠팡 파트너스, 알리 제휴 API 등)로 수집하는 서버가 필요합니다.
- **카드 혜택 정확도**: AI가 모르는 카드는 혜택을 비워 둡니다. 카드 혜택 규칙 DB가 필요합니다.
- **사진첩·문자 자동 읽기**: 웹 페이지는 사용자가 고른 사진과 붙여넣은 글만 읽을 수 있습니다. 실제 앱에서도 iOS는 다른 앱의 문자를 읽을 수 없고, 안드로이드는 구글 플레이 정책상 문자 읽기 권한이 기본 문자 앱 등 일부에만 허용됩니다. 카드 결제 내역은 마이데이터로, 일정은 캘린더 권한으로 받는 쪽이 현실적입니다.
- **토스처럼 자동 연동**: 카드 실적·포인트 잔액을 자동으로 불러오려면 마이데이터 사업자 허가를 받거나 허가받은 회사와 제휴해야 합니다. 그 전까지는 한 번만 직접 등록합니다.
