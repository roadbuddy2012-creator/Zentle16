# 천샵 — 뭐든 천 원

사진이나 쇼츠로 물건을 올리면 **새것이든 중고든 무조건 1,000원**인 동네 마켓의 안드로이드 시제품입니다. 화면은 인스타처럼 단순하게, 거래 안전장치는 당근 방식을 따랐습니다.

## 설치

1. 휴대폰에서 이 저장소의 [Releases](https://github.com/roadbuddy2012-creator/Zentle16/releases)를 열고, 가장 위의 `천샵 시제품 0.1.x`에서 `cheonshop-0.1.x.apk`를 내려받습니다.
2. 설치할 때 "출처를 알 수 없는 앱 설치"를 허용합니다.
3. 새 버전은 지우지 않고 덮어 설치하면 됩니다. 모든 빌드가 같은 시제품 서명 키로 서명됩니다.

APK는 `cheonshop/**`가 바뀌어 이 브랜치나 `main`에 푸시될 때마다 GitHub Actions(`.github/workflows/cheonshop-apk.yml`)가 만들어 프리릴리스로 올립니다.

## 화면

| 화면 | 하는 일 |
| --- | --- |
| 처음 시작 | "뭐든 천 원" 소개 → 닉네임·동네 입력, GPS 동네 인증(선택) |
| 홈 | 인스타식 피드. 동네·인증 표시, 전체·새것·중고·택배 가능 보기, 사진 넘기기, 영상 자동 재생(소리 끔), 찜·문의·원해요 |
| 쇼츠 | 영상 먼저, 한 화면에 하나씩 세로로 넘겨 보기 |
| 올리기(+) | 앨범·사진 찍기·쇼츠 찍기로 최대 10개(영상 1분까지) → 제목·설명·새것/중고·택배 가능·만날 곳. 가격은 1,000원 고정, 금지 품목 확인 |
| 물건 | 사진·영상, 판매자 매너온도, 거래 방법, 안전 안내, 아래에 `1,000원 · 원해요` |
| 채팅 | 원해요를 누르면 열림. 약속 잡기(밤 9시 이후 경고), 택배로 받기(택배비는 받는 사람 부담), 거래 완료와 후기, 노쇼 신고. 전화번호·계좌·메신저 아이디를 보내려 하면 한 번 더 확인 |
| 나 | 인스타 프로필형. 올린 물건·거래완료·찜 그리드, 매너온도, 프로필 편집, 설정 |

## 안전장치 (당근 방식)

- **동네 인증과 매너온도:** GPS로 동네를 인증하고, 판매자 옆에 매너온도를 보여 줍니다.
- **첫 거래 전 안전 수칙:** 공개된 장소, 밝은 시간, 물건 확인 후 현장 결제, 선입금 금지를 확인받습니다.
- **채팅 경고:** 연락처나 계좌를 주고받거나 앱 밖으로 옮기자는 말이 나오면 경고합니다.
- **후기와 노쇼:** 후기와 노쇼 신고가 상대의 매너온도에 반영됩니다.
- **금지 품목:** 주류, 담배, 의약품, 반려동물 등은 올리기 전에 금지 품목이 아닌지 확인받습니다.

## 시제품이라 아직 안 되는 것

- **서버가 없습니다.** 글·사진·영상·대화는 그 휴대폰(IndexedDB)에만 저장되고 다른 사람에게 보이지 않습니다. 채팅은 상대에게 전달되지 않고, 앱이 그렇게 안내합니다.
- **예시 물건 8개가 들어 있습니다.** 화면을 보여 주기 위한 손그림 일러스트이고, "예시"로 표시됩니다. 설정에서 숨길 수 있습니다.
- **여러 사람이 함께 쓰려면 서버가 필요합니다.** 예를 들어 Firebase나 Supabase 같은 저장소와 로그인을 붙여야 합니다. 이때 법적 의무도 생깁니다. 개인 간 거래를 중개하므로 통신판매중개업 신고를 하고, 판매자 신원 확인 체계를 갖춰야 합니다.

## 개발

```bash
cd cheonshop
npm ci
npx cap sync android      # www → android/app/src/main/assets/public
# 안드로이드 SDK가 있으면: cd android && ./gradlew assembleDebug
```

- 웹 앱은 `www/` 아래에 있고, 프레임워크 없이 순수 JS로 만들었습니다.
- 글꼴은 Pretendard(OFL-1.1)이며 `www/fonts`에 라이선스와 함께 들어 있습니다.
- `android/cheonshop-test.keystore`는 시제품 업데이트 설치용 고정 서명 키입니다. 스토어 출시용 키가 아니니 출시할 때는 새 키를 만들어 비밀로 관리하세요.
