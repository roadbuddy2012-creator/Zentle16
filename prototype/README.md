# 알구싸구 — 사용 가능한 시안

`algussagu.html` 한 파일로 된 웹 앱입니다. claude.ai 아티팩트로 게시해서 쓰며, 아티팩트가 주는 기능(`sample` AI 호출, `db` 사용자별 비공개 저장, `user`, `comments` 의견 남기기)을 사용합니다. 그 밖에서는 AI 없이 이 기기 브라우저에만 저장되는 모드로 동작합니다. 이전 이름은 "곁"(`gyeot-app.html`)이었고, 계정에 남은 곁의 결제수단·취향·옷장 이름은 처음 열 때 한 번 옮겨 옵니다.

## 흐름

탭은 셋입니다. **물어보기 · 연예인 코디 · 내 지갑**.

1. **물어본다** — 아래 입력창에 말하듯 적거나 사진을 보냅니다.
2. **결과부터** — 되묻지 않고 바로 2~3개를 보여 줍니다. 쿠팡·네이버쇼핑·무신사·11번가·올리브영·알리·테무 등에서 평점·리뷰·판매량이 함께 높은 스테디셀러를 우선합니다. 상품마다 "○○에서 보기"(판매처 검색, 쿠팡은 판매량순·네이버는 리뷰 많은순)와 "사진 보기"(네이버 이미지 검색) 버튼이 있고, 결과 아래에 사이트별 검색 결과 링크를 모아 둡니다.
3. **대화로 다듬기** — 결과 아래 질문 하나와 다음 요청 칩("3만 원 아래로", "더 가볍게")으로 결과를 다시 만듭니다. 대화에서 알게 된 키·사이즈·가진 옷·취향은 기억해 두고 다음 쇼핑에도 씁니다.
4. **카드는 마지막에 한 번** — 결과를 본 뒤에만 "카드 찍어서 올리기"를 권합니다. AI는 카드사와 상품명만 읽고, 카드 번호·유효기간은 읽거나 저장하지 않으며 사진도 저장하지 않습니다. 한 번 등록하면 다시 묻지 않고, "나중에"를 누르면 더 권하지 않습니다.
5. **가장 싸게 결제하는 법** — 등록한 카드·Pay·포인트·멤버십을 조합해 계산합니다.

연예인 코디 탭은 이름이나 스타일("올드머니 룩"), 자리(출근룩·하객룩 등), 예산을 고르면 부위별 코디를 찾아 물어보기 탭에 보여 줍니다. 실제 착용 제품이 아니라 비슷한 분위기의 제품이라고 표시하고, 사진 속 인물이 누구인지는 추측하지 않습니다.

## 결제 조합 계산 (AI가 아니라 코드가 계산)

- 주문마다 카드·Pay를 배정하는 모든 경우를 따져 실제 부담(할인·캐시백·적립 반영)이 가장 적은 조합을 고릅니다. 카드별 월 할인 한도는 주문끼리 나눠 씁니다. 예: 한도 1만 원 카드는 가장 비싼 주문보다 할인율이 높은 작은 주문 둘에 쓰는 게 이득일 수 있습니다.
- 온라인 결제는 보통 주문 1건에 카드 1장이라, 카드 2장을 쓰려면 주문을 나눕니다. 주문을 나누면 배송비가 따로 붙는 것도 계산에 넣습니다.
- 포인트는 카드 혜택을 깎지 않는 주문에만 쓰고, 깎이면 아껴 두는 쪽이 얼마나 이득인지 알려 줍니다.
- 멤버십은 무료배송과 추가 적립을 반영합니다(쿠팡 와우·배민클럽은 무료배송이 기본값).
- 무이자 할부가 되는 카드는 월 부담도 보여 줍니다.

## 서버나 제휴가 있어야 되는 것

- **상품 사진과 상품 페이지 링크**: claude.ai 아티팩트는 보안 정책상 다른 사이트의 이미지와 데이터를 불러올 수 없습니다. 그래서 지금은 상품의 대표 색과 종류로 타일을 그리고, 사진은 링크로 엽니다. 실제 앱에서는 네이버 쇼핑 검색 API처럼 상품 사진·상품 페이지 링크·최저가를 주는 API를 서버에 붙이면 바로 보여 줄 수 있습니다.
- **실시간 평점·리뷰 수·판매량 순위**: 이 페이지는 외부 사이트를 읽을 수 없고, AI도 실시간 검색을 하지 않습니다. 결과는 AI가 아는 정보 기준이며 가격은 예상가입니다. 제휴 API(쿠팡 파트너스, 알리 제휴 API 등)로 수집하는 서버가 필요합니다.
- **카드 혜택 정확도**: AI가 모르는 카드는 혜택을 비워 둡니다. 카드 혜택 규칙 DB가 필요합니다.
- **토스처럼 자동 연동**: 카드 실적·포인트 잔액을 자동으로 불러오려면 마이데이터 사업자 허가를 받거나 허가받은 회사와 제휴해야 합니다. 그 전까지는 한 번만 직접 등록합니다.
